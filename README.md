## [Publish and distribute a plugin:](https://code.claude.com/docs/en/plugins/publish)
Publish a Claude Code plugin through your own marketplace or Anthropic’s directory, with a pre-release checklist and how users get updates.
See [Choose how to distribute:](https://code.claude.com/docs/en/plugins/publish#choose-how-to-distribute)
Publishing a Claude Code plugin means listing it in a marketplace, a JSON catalog that lists plugins and where to fetch each one, so that other people can install it by name and receive your updates. You can run your own marketplace.
