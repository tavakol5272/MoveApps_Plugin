# Dealing with secret credentials

- Some Apps require sensitive credentials such as passwords, personal API keys, access tokens, client secrets, or other authentication credentials.
- To ensure Claude does not request, expose, store, or hard-code real credentials, read and follow the MoveApps documentation on [dealing with passwords](https://docs.moveapps.org/#/create_app?id=dealing-with-passwords).
- Apply these rules whenever the App uses a `SECRET` setting or otherwise requires sensitive authentication information.
